# Проект: `courswork`
Анализ финансовых данных и транзакций

## Описание:
Проект предоставляет API для анализа финансовых данных, 
генерации отчетов и реализации сервисов для работы с транзакциями.

## Установка:
1. Клонируйте репозиторий: git clone https://github.com/dj3747/coursework
2. Установите зависимости через Poetry:
- создаём файл `.gitignore`
- создаём файл `pyproject.toml` командой `poetry init`
- добавляем `poetry add --group dev pytest`
- добавляем в группу линтеров 
  `poetry add --ggroup lint (flake8, black, mypy, isort)`
- создаём при необходимости в корне проекта файлы:`.flake8, mypy, config.py`
- устанавливаем библиотеку `pandas`- `poetry add pandas`
- для генерации отчётов о покрытии тестов в HTML-формате добавляем:
  `pytest --cov=src --cov-report=html`

## Настройте переменные окружения:
1. Создайте файл `.env` на основе файла `.env.example`
2. Добавьте API-ключи


## Структура проекта
Проект состоит из следующих модулей:
1. `utils`
2. `views`
3. `services`
4. `reports`
5. `main`


## Проверка кода
В проекте выполнены проверки линтерами:
- `flake8`: для проверки стиля кода
- `mypy`: для статической типизации
- `black`: для автоматического форматирования кода
- `isort`: для сортировки импортов


## Тестирование
Для тестирования используется библиотека `pytest`.
Покрытие тестами составляет не менее 80% кода проекта.
